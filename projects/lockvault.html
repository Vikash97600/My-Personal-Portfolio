01 / OVERVIEW

Problem & Solution

The Problem

Centralized, cloud-hosted password managers create catastrophic single points of failure where server breaches, compromised master vaults, and backend API leaks expose confidential credentials. Traditional web apps frequently transmit sensitive authentication payloads over networks, leaving users vulnerable to man-in-the-middle attacks and third-party data compromises.

The Solution

LockVault is a pure zero-knowledge, client-side password vault engineered entirely on browser-native cryptographic standards. All encryption, key derivation, and decryption routines execute exclusively inside isolated browser memory using the Web Crypto API. Unencrypted plaintexts never touch local storage unencrypted or traverse external networks, providing full data sovereignty with optional biometric (WebAuthn) passkey unlocking.

02 / FEATURES

Security & System Features

AES-256-GCM Encryption

Authenticated symmetric encryption providing both confidentiality and integrity verification, ensuring encrypted records cannot be modified without detection.

PBKDF2 Key Derivation

Derives high-entropy master cryptographic keys from user master passwords using SHA-256 with 100,000 salt iterations to prevent offline dictionary and GPU brute-force attacks.

WebAuthn Biometric Unlock

Hardware-backed biometric authentication (Touch ID, Windows Hello, Face ID) for convenient local vault re-authentication without storing raw master passwords.

Shannon Entropy Analysis

Mathematical password health analyzer computing theoretical entropy score and pattern repetition to identify weak or compromised credentials in real time.

IndexedDB Local Persistence

High-capacity structured client storage holding encrypted ciphertext vaults locally without relying on insecure standard localStorage.

Offline-First PWA Support

Service Worker architecture enabling instant standalone installation and full offline access with zero server dependency.

05 / ENGINEERING DECISIONS

Security Decisions & Trade-Offs

  • Zero-Knowledge Memory Isolation vs. Cloud Sync: Deliberately eliminated backend server synchronization to guarantee zero exposure risk. All plaintext transformations occur strictly in volatile JavaScript heap memory and are wiped upon session expiration.
  • 100,000 PBKDF2 Hash Iterations: Selected 100,000 rounds of PBKDF2 with SHA-256 as an optimal equilibrium between defending against GPU brute-force cracking and maintaining sub-150ms key derivation latency on mobile browsers.
  • WebAuthn Biometric Token Wrapping: Engineered WebAuthn passkey authentication to unlock session master keys from device hardware enclaves (Secure Enclave / TPM), preventing password shoulder-surfing while preserving zero-knowledge guarantees.
