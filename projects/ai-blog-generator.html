AI Blog Generator

YouTube-to-Blog AI Content Pipeline

Python Django yt-dlp AssemblyAI OpenRouter LLM
GITHUB REPOSITORY →
01 / OVERVIEW

Problem & Solution

The Problem

Repurposing long-form video content into written publications requires tedious manual transcription, formatting, translation, and summary synthesis.

The Solution

AI Blog Generator is an automated Django pipeline that takes any public YouTube URL, extracts audio streams via `yt-dlp`, processes high-accuracy transcription through AssemblyAI, and uses OpenRouter LLM APIs to generate structured, formatted articles with multi-language translation, TTS audio generation, and PDF exports.

02 / FEATURES

Pipeline Features

Video Stream Extraction

Leverages `yt-dlp` to extract clean audio payloads from YouTube videos efficiently without downloading full video streams.

Speech-to-Text Processing

Integrates AssemblyAI APIs for automated speaker identification and timestamped transcript generation.

LLM Article Synthesis

Prompt-engineered LLM workflows synthesizing raw transcripts into key takeaways, structured headings, and formatted markdown blogs.

Multi-Language Translation

Translates generated articles into Hindi, Marathi, and regional languages with text-to-speech audio playback.
