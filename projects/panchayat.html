01 / OVERVIEW

Problem & Solution

The Problem

Co-operative housing societies in India face significant administrative fragmentation: resident grievances are often delayed via unorganized manual messaging, visitor tracking relies on physical logbooks, bylaw queries require searching lengthy PDF records, and emergency alerts lack real-time escalation channels.

The Solution

Panchayat consolidates society management into a role-based Django platform with an integrated AI core. It automates complaint categorization, enables voice-assisted bylaw querying in regional languages, streams maintenance tracking, and manages secure gatekeeping for residents, security personnel, and administrators.

02 / FEATURES

Core System Features

AI Complaint Processing

Automatically analyzes incoming resident issues, assigns priority levels, categories (plumbing, electrical, administrative), and routes notifications directly to assigned vendors or committee members.

Bylaw Assistant

Multilingual voice and text AI query interface allowing residents to ask natural questions about society rules, parking policies, and maintenance guidelines.

Role-Based Access Control

Custom authorization matrix segregating Resident, Security Guard, and Society Admin interfaces with granular data access permissions.

Visitor Management

Digital gatepass entry workflows allowing security guards to log guest entries and request instant digital approval from flat owners.

Emergency Workflows

One-tap emergency broadcast system sending high-priority alerts to security personnel and committee members during incidents.

05 / ENGINEERING DECISIONS

Technical Decisions & Trade-Offs

  • Django Group-Based Authorization Matrix: Implemented explicit Django permission groups to strictly isolate security guard gatepass access from administrative ledger and resident grievance records.
  • Fallback Prompt Templates for AI Services: Standardized structured JSON responses from LLM endpoints for complaint classification to prevent unstructured parser failures in production.
  • Relational Schema Normalization: Separated Flat Ownership, Member Contacts, Maintenance Records, and Visitor Logs into distinct database tables with index constraints to support fast query lookups.
