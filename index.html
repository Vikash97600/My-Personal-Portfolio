Project Summary

MediBuddy was engineered to solve a critical healthcare challenge: medication non-adherence among elderly and chronic patients. By integrating low-cost IoT hardware with cloud-based tracking, we developed a system that reminds patients and alerts caregivers in real-time.

Technical Core

  • Built using ESP8266 NodeMCU
  • Firebase Cloud Messaging for IoT communication
  • DS3231 RTC module for precise timing

User-Centric Design

  • LED + Buzzer alert system
  • Physical push-button for intake confirmation
  • Mobile dashboard with "Adherence Score"

Impact & Cost

  • 50% cost reduction vs market solutions
  • Prototype cost: ₹2,200 - ₹2,500
  • Real-time medicine logs for doctors

Research Methodology

1

Requirement Analysis

Defined technical constraints for low-income and rural healthcare needs following University of Mumbai's research platform standards.

2

Hardware Architecture

Selected optimized components for affordability and battery life to ensure practical deployment in real-world scenarios.

3

Performance Validation

Conducted unit and integration testing to ensure network stability and alarm accuracy throughout development lifecycle.
